  • [2025-08-31] vscodevim 从 normal 切换为 insert 时输入中文会出现错位, 可以设置 vim.autoSwitch 有关的四个选项实现自动切换, 有效且简洁.

    • 浏览器搜索 brew im-select, 会找到相应的 github 仓库, 比如 AAA/im-select, 然后安装

    brew tap AAA/im-select
brew install im-select

    • 分别在英文和中文输入法下在终端执行 im-select (可以用 which im-select 查看完整路径), 查看两种输入法的 ID, 然后设置 vim.autoSwitch 的内容:

    "vim.autoSwitchInputMethod.enable" :true
"vim.autoSwitchInputMehtod.defaultIM": "com.apple.keylayout.ABC"
"vim.autoSwitchInputMethod.obtainIMCmd": "opt/homebrew/bin/im-select"
"vim.autoSwitchInputMethod.switchIMCmd": "opt/homebrew/bin/im-select {im}"

    • 如果 normal 模式下敲击 i 时没有进入 insert 模式而是显示中文输入, 应该是 im-select 还没切换好呢就触发了 i 键输入, 可以在 switchIMCmd 中添加延时:

    "vim.autoSwitchInputMethod.switchIMCmd": "opt/homebrew/bin/im-select {im} && sleep 0.1"

  • [2025-08-25] github 进行 pull 时不支持使用密码验证, 可以使用 Personal Access Token（PAT）+ HTTPS 或 SSH + GIT 等方式验证（QianWen 还给出了其他验证方案，好繁琐）。

    看起来 SSH + GIT 最简便：

    1. 生成 SSH 密钥：ssh-keygen -t ed25519 -C "your_email@example.com"

    2. 将公钥（~/.ssh/id_ed25519.pub）添加到 GitHub：Settings → SSH and GPG keys → New SSH key

    3. 改用 SSH 地址：git remote set-url origin git@github.com:username/repo.git

  • [2025-07-07] 局域网内使用 samba 共享文件, ubuntu 需要安装, Mac 内置了访问功能.

    sudo apt-get update
sudo apt-get install samba

    对共享的文件夹 /path/to/shared/folder 设置权限 (777 是完全控制)

    sudo chmod 777 /path/to/shared/folder

    修改 samba 配置文件, 通常位于 /etc/samba/smb.conf, 在文件最后添加要共享的文件夹信息

    [shared]
path = /path/to/shared/folder
available = yes
valid users = your_user_name
veto files = /._*/.DS_Store/
read only = no
browsable = yes
public = yes
writable = yes

    对 ubutnu 用户名设置访问密码, 并重启 samba 服务

    sudo smbpasswd -a ubuntu_user_name

sudo systemctl restart smbd # sudo service smbd restart

# sudo systemctl status smbd
# sudo systemctl start smbd
# sudo systemctl stop smbd

    在 Mac 的访达中, cmd + k 或菜单栏前往, 打开连接服务器, 地址栏输入smb://ip_or_hostname/shared.

    • 设备很多时, ip 不易识别, 可以用 hostname 命令查看主机名, 用起来很方便.

    • shared 是 samba 配置信息中括号内的标题

    • 登陆需要输入的用户名是 ubuntu 上设置的用户名称, 不是 Mac 上的个人用户名称.

    • a && b 的 b 仅当 a 为 true 时才被执行.
